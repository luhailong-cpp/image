# 登录页原稿恢复

本轮接续用户“包括登录界面也不对”的要求。现存完整登录稿为 [01_login_2560x1080.png](../../01_login_2560x1080.png)，它是登录首页，包含公告、设置、当前服务器、进入游戏与切换账号。历史制作说明没有把账号密码表单画进这张首页稿。

首页继续使用这张已确认原稿，没有另换画风。上轮清图移除了右上角入口，并把主按钮固定书法字改为近似字体；这次恢复原图静态像素。只有当前服务器的名称、状态和圆点区域使用已有清图纸底覆盖，再由原生控件显示真实数据。静态按钮字保留原画，点击、选服、账号输入及进入流程仍是 Unity 控件。

资源来自 `tools/ui-fidelity/restore-original-login.py`，安装清单为 `art-install-manifest.json`。每张派生图旁保留独立来源记录。本轮没有调用生成模型；历史原稿的实际型号、质量没有可靠记录，保持未确认。已有清图的小块来源另沿用其原始内置调用记录。

`source-geometry.json` 记录原稿坐标；`qa/original-pixel-checks.json` 检查不可变原画区域。账号表单及公告、设置弹窗沿用现有玉纸控件体系，它们没有独立历史整屏效果图，不冒称逐像素复原了不存在的原稿。

原生截图与交互验收正在随本轮接入更新，最终结论以 `qa/final-review.json` 和本轮 Unity 结果为准。

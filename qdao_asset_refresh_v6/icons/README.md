## 制作与尺寸

使用内置 `image_gen`，遵循 `generate2dsprite` 的紧凑物件包、纯洋红底、完整轮廓和透明验收流程。前七批为 4×4、原生 1254×1254；最后一批为 4×3、原生 1448×1086。600×600 是最终透明导出尺寸，经过重采样，不宣称每枚有 600 原生 AI 像素。

原生图的格距略有变化，处理器先在纯洋红的完整间隔带中寻找分隔线，再无损平移每一格到带留白的规整画布。随后用技能处理器清底、保留主体、独立切格和居中导出。最终仅移除重采样产生的残留洋红边像素；没有用代码绘制或替代物件美术。每枚保留透明外边距。

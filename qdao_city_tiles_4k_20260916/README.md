# 主城单块4K重制

四个地点、七套外观全部采用最高质量重绘，每个交付块4096×4096无损PNG。整图分辨率由最终行列数量决定，不固定16K。完整规则见[Image切图.md](../Image切图.md)。

当前状态：已准备天墉城中央广场首块的4张布局参考、4份手写提示词及确定性拼接工具。**新生成图片数量为0；参考裁图不是新高清资产；未替换客户端地图。**

首块取自现6144图的(2048,2048)-(4096,4096)，对应世界X=150..250、Z=100..200，只用于验证重绘细节、太极纹样、台阶、道路与接缝，不据此固定全城分块数量。全图数量还需按最大近景的屏幕像素密度确定，样块通过不等于全图最近景清晰度通过。

## 制作与拼接

目标模型为 gpt-image-2.5-sunburst-2026-09-08，质量max。每个4096块由4张2304×2304原生重绘组成；每张2048核心及每边128上下文，相邻重叠256。四张拼成4352×4352含外围上下文候选，再裁中央4096×4096；最终艺术像素不插值放大。保留4352上下文供相邻4K块接缝使用。

参考裁图保持1152×1152原尺寸，明确标为layout-only；已有素材只提供布局，新增细节须来自真实生成。复用现有最小误差接缝算法与窄羽化；地标、道路或台阶错位必须重绘，不靠模糊掩盖。

运行 python pipeline.py prepare 仅裁参考、记录哈希，不生成提示词、不调用API。运行 python pipeline.py assemble 要求四张真实原生PNG及generation-records.json，核对型号、质量、尺寸、哈希及请求标识，缺少即退出。只输出待审候选，不创建生产Resources manifest。像素检查不能证明所有纹理是真细节，仍须100%像素视觉验收。

每条生成记录含id、model、quality、nativePixels:[2304,2304]、requestId、promptSha256、outputSha256。实际值来自真实请求/返回与原始文件，不预填成功状态。若调用入口未返回请求标识，保留可验证的调用记录并明确调整记录合同，不能编造ID。

正式生图使用已有gpt-image CLI，不新增API实现。逐次传入对应手写提示词、局部参考及现有全城参考，显式指定模型、size=2304x2304、quality=max、PNG输出；依次审查四张。已接受的相邻分区可追加为衔接参考。其他地图保留各地域自然配色，不能全部改成天墉的玉绿暖金。

## 执行入口

核对日期2026-09-16。[官方Sunburst页面](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)提供上述快照；[官方图片指南](https://developers.openai.com/api/docs/guides/image-generation)限制单边不超过3840及总像素上限，不能单次原生生成4096方图。2304方图在公布尺寸边界内，大尺寸效果仍须实测。

[官方内置生图说明](https://learn.chatgpt.com/docs/image-generation)仍标为gpt-image-2，本会话内置无模型/尺寸选择器，未将内置生成冒称2.5。本地CLI已存在，但未在本进程环境或CLI常用项目/用户.env路径发现密钥配置。未输出秘密值。

锁定2.5需要授权单独计费API并在本机安全配置OPENAI_API_KEY，不在聊天中提交密钥。当前未发出API请求或计费。待授权先执行首块4次最高质量原生重绘并拼接验收，再根据实测近景、镜头缩放和设备性能安排全部七套外观。

## 验收

检查原生尺寸、PNG完整性、来源；100%审看石纹、屋瓦、植被及轮廓，排除虚焦与锐化白边；检查内部交叉接缝和外缘上下文；对照道路、台阶、建筑、水岸及现有导航；客户端验证最近景、宽屏、跨块移动、换景、闪烁、内存峰值和释放。全部通过才发布完整地图manifest。

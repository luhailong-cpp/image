# r09_c11 原生制作工具

本目录只准备输入、登记兼容任务和装配原生像素，不调用生图、不更新总进度、不自动验收。

1. 把已审查的 1254×1254 区域引导图保存为 `r09_c11/regional/shared-region1254.png`。它仅供构图引导；放大后的像素不能进入正式成图。
2. 实际查看待做区域及风格参考，运行 `prepare_native.py 1 1 --description "只描述此裁图中实际可见的内容"`。它输出 `guides`、`prompts`、`jobs`。必须先有已登记的西邻、北邻；同一对角线可并行，同一行从左到右。16 块位置采用 1024 步长，原生 1254，重叠 230，外环 115。
3. 查看输出 guide 及 `designs/gameplay-ui/04-guild.png` 后，通过内置 imagegen 使用 job 中的 prompt 和两张参考图。工具无型号/质量选择器时实际值保持 null。保存真实工具回执与实际完成时间，再调用现有 `lanxian_spring/tools/register_job.py --job <job.json> --result <真实回执.json> --source <实际工具输出.png> --generated-at <带时区时间>`。
4. 16 张原生图均已登记后运行 `assemble.py`。它生成 `assembly_hardcut`，拒绝覆盖。后续版本使用 `--output-name assembly_hardcut_v2`。全部输出逐像素验证来源，任何上采样、移位、调色和混合均为零。
5. 实际审查 `qa` 内 24 段内缝、9 个交点、4 段西邻与 4 个外角（共 41 张，均 1:1）。有问题再建立带蒙版、参数、来源及复核的局部修补；本基线不掩盖缺陷，也不会标为通过。

西侧固定读 `r09_c10/selected-v2/extended4326.png`，SHA `3532108ee8d5eab3f85bee5abb83924e5df41c2a1126b08554a6c754d0bd917d`。每行第一块从其 x=4096..4326 读取 230×1254 原生上下文；坐标随该行 y 增加 1024。指南交点的优先级从低到高为内部西邻、北邻、外部西邻，记录重叠冲突量，不能声称所有冲突参考都完全一致。装配时只固定外部西侧 115 像素 halo，本块 4096 核心仍完全由其 16 张原生图组成。

所有输入 SHA、参考坐标、原生来源与未完成 QA 均写入 JSON。此工具不产生新生图记录，不把指南放大或装配声称为原生生成。已有任务输入及候选目录不可覆盖，防止生成证据失去对应关系。

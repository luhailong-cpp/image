# Parent repairs and retained sources

The five selected repair PNGs and their 37 exact QA crops are in [current](current/README.md). They are parent review candidates; the seven child selections, new-coordinate count, formal acceptance and runtime acceptance are unchanged.

The current directory is an immutable export snapshot. Its README and bound provenance describe source availability when exported. The authoritative later availability overlay is [retirement.json](retirement.json): every listed removed path is a historical source identity, with its original SHA256 preserved, `imageRetained=false` and `runtimeDependency=false`. Unchanged generation, model, quality, prompt and review records remain available. A historical image path is not an instruction to recreate that image.

The original [cleanup proposal](cleanup-proposal.json) is preserved as planning evidence. Its image-capsule proposal was replaced with a verified method that creates **no image backups**: the current five outputs, four original local contexts and four masks are retained. [migration-manifest.json](migration-manifest.json) stores exact changed-pixel runs and source/context coordinates. Original pixels at those runs are restored from the contexts; unchanged pixels, including the full 128px verification halo outside a context crop, already remain in current. [migration-verification.json](migration-verification.json) confirms that this exactly reconstructs every baseline and reproduces all five selected outputs.

Use [rebase_current.py](rebase_current.py) for future migration. Running it with no arguments verifies retained inputs without writing images. `--checkpoint ABSOLUTE_CANDIDATE_SET_JSON` checks a newer selection without writing images. Add `--execute --output ABSOLUTE_NEW_DIRECTORY_INSIDE_THIS_PARENT_DIRECTORY` only when a new parent candidate is needed. The destination must be new and outside `current`; child files are never overwritten. The tool rejects changes within a repair's 128px halo unless the identical repair is already present, and preserves every pixel outside the exact repair support. Conflicting new local artwork needs review, not repeated generation of retired inputs.

[Retired scripts](retired-scripts.json) are historical implementation evidence. Their original branch/native inputs are no longer runtime dependencies. `integrate_current.py` is explicitly blocked after retirement; use the new entry point above. Branch build and preparation scripts must not be rerun against this immutable snapshot.

[retirement.json](retirement.json) records each actual deletion, byte count, last external-reference scan and before/after hashes for current outputs, retained contexts/masks and all preserved text. [external-reference-scan.json](external-reference-scan.json) is the immediate pre-deletion scan of sibling task text; the preceding independent audit also searched the entire image project and the client project. No files outside this parent directory, no child artwork and no host caches are in this deletion scope.

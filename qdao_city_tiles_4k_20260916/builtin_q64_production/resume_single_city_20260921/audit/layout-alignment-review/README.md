# 天墉节庆布局独立对照

已实际查看本目录 9 张对照图板。历史 plaza 与原 6144 中央区域的大地标位置近似保留；这次抽样未见整片严重平移或道路开口换位。r09_c09 v6 与 r09_c10 初版的环线和大型纹样也仍在原区域，但石板分缝、浮雕/云纹、亮暗边宽度明确变化，不能宣称几何逐像素相同。

本目录仅为同坐标、主动缩放的布局分析预览。图板不算原生清晰度证据、不算正式图块，也不替代接缝、四块交点、导航或客户端实机验收。源、候选和 9 张图板的 14 项 SHA 在写报告时重新核对一致。

## 可复核的观察位置

- `plaza_geometry_overview.jpg` 和两张 navigation overlay：原 6144 大约 `[2870,2090,3270,2490]` 的北台阶与通道、`[2580,3750,3560,3980]` 的南台阶开口、中央同心环及南侧两盆景基座均仍处于相应区域。坐标为检查范围，不是测得的偏移量。
- `r09_c09_geometry.jpg`：v6 图块内 `[0,1750,1000,3100]` 的深色径向铺装条带及 `[1700,2150,2850,2800]` 的嵌板云纹存在边宽/刻纹/分缝重绘。结合整城图，这里的深色条带是中央环面的装饰，不能仅凭局部外观认定为实际新增楼梯或阻挡。
- `r09_c10_geometry.jpg`：初版图块内 `[2400,600,4096,2550]` 的云纹内卷线变粗，附近地砖格缝有变化；左侧环边与斜向铺装带的大方向仍近似保留。此板不是后来的 internal-v4 或外部拼接版本验收。
- `r08_c09_geometry.jpg`：原 6144 `[3072,2688,3456,3072]` 的太极黑盘、白色鱼眼、金色弧边位置近似；装饰线条已重描。本区域仍主要是环面，没有看到建筑、门洞、桥栏或岸线。
- `r09_c11_geometry.jpg`：原 6144 `[4096,3072,4224,3456]` 对应 plaza 之外，恰涉及右下弧形护栏、水岸、树木。分析板右侧紫色 256/768 像素是无来源，等价于目标图块最右约 1365.33 像素；不能当作普通地砖外推。

## 接续建议与验收界限

优先继续 r08_c09。用原 6144 约束太极、同心弧边与整体方向，plaza 只作风格/局部细部参考，同时接续当前 r09_c09 上边。

r09_c11 先从原 6144 提取包含完整护栏、水岸、树木基底的布局上下文，尤其锁定约 `[4080,3245,4140,3390]` 的立柱区和 `[4096,3220,4224,3456]` 的弧形护栏/岸线区，再原生细化。不得由旧 plaza 缺失边外推，也不得改导航迁就美术猜测。

两张导航叠图实际看过，既有障碍附近未见明显的大实体错位。但多边形来自同一份 navigation.json，静态 mask/坐标/SHA 相同不能证明 Q64 导航一致。全量道路边界、楼梯上下关系、树冠遮挡、通行碰撞及实机仍未完成。正式美术、完整导航、客户端实机和整城验收均保持 false。

精确来源版本、SHA、观察区域和限定条件见 `layout-review.json`；图板变换见 `comparison-manifest.json` 和 `prepare_comparisons.py`。没有更改候选、源、客户端或根级状态记录。

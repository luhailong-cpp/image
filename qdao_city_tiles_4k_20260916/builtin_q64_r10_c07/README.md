# 天墉城 Q版 · 64K密度首块4K样图

本轮使用用户选定的内置生图入口，不调用单独计费API，也不需要API Key。交付对象是整城64K方案中的一个局部样图：天墉城节庆 r10_c07，世界范围 X=162.5..181.25、Z=112.5..131.25；不是完整64K主城。

## 本轮实物

- [4096×4096无损PNG样图](output/tianyong_r10_c07_q64_4k_candidate.png)
- [1024总览](qa/overview_1024.png)
- [原像素树冠细节](qa/tree_upper_left_100pct.png)、[原像素花坛细节](qa/garden_lower_left_100pct.png)、[原像素栏杆与台阶](qa/garden_stairs_lower_right_100pct.png)
- [完整来源与拼接记录](output/assembly.json)、[17张原生图的模型元数据读取](qa/builtin-model-audit.json)

先由内置工具生成统一Q版布局参考，再逐区域生成16张1254×1254原生细节图。每张保留1024核心和各115上下文，相邻重叠230；拼成4326方图后外围各裁115，得到4096×4096。

最终图由原生细节图机械拼接，没有放大最终美术、全图锐化、全图模糊或混入放大的参考像素。布局参考的插值仅用于指导每张重绘；来源PNG原样保存。完整手写提示词在prompts目录，实际传入的JPEG参考及SHA记在逐张record内。

风格强化圆润饱满的叶簇、花瓣、绳结和石构件，画面明亮干净，减少写实裂纹与颗粒。保留原有镜头、主体布局和地面路径；既有前景与新Q版造型兼容性仍需独立验收。

## 检查与范围

机械拼接与再次读取校验通过：16份原生来源、4096²输出和13份标准QA文件一致，9个四块交点均有900²原像素裁图；另补充顶部铺装、左侧树干、底部栏杆、右上石条的原像素边缘检查。

C2PA读取显示统一参考和16份原生图的生成动作均标注gpt-image 2.0。该读取不等于密码学验签或可指定后端；工具没有开放型号、质量或尺寸选择器。

[独立视觉复核](qa/independent-visual-review.md)已查看总览及九个原像素交点，所看范围没有明显结构断裂、错位或方格色差；[补充边缘检查](qa/root-visual-review.json)覆盖树冠、花坛、栏杆、台阶及指定边缘局部。当前仅作为更Q版和高清密度样图。全部七套外观的1792个正式4K块尚未完成；相邻正式4K块、完整主城、游戏最近镜头、前景、设备内存仍需验收，本图尚未替换到游戏。客户端分块加载与换景代码已另行完成21项EditMode测试。

运行 `python assemble_builtin.py --check` 可复核本次来源与产物。不要修改已记录的plan、原生图或prompt后仍沿用旧assembly记录。

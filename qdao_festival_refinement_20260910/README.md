## 开始后的处理顺序

先重新核对相关出图任务及其最终验收，再刷新清单并确认实际最新来源。按来源处理，派生输出随后同步：

1. 场景与地图：核对新主城画法、既有母图、36 张切片与宽屏场景的用途；保留清楚的道路、地标、战斗留白与接缝。
2. UI 和属性：承接 v10 最终原画与切片，保留深玉绿、象牙纸质、细暖金边；必要节庆点缀随母件同步到兼容路径，保留已删除“相性点”的功能修订。
3. 人物、动作和宠物：以 v9／v11 各自最终交付为输入；保持直发、职业差异及真实动作。旧动作和新增包的帧数、画布及锚点各自保留，不互相覆盖接口。
4. 物件、徽标和图集：逐项检查节庆适用性，现有道家识别已合适的内容可记录保留理由；正式图集须从最终单件同步重建。
5. 汇总每个正式文件的处理或保留理由，检查曝光、透明边缘、文字、状态、地图接缝、动作和同源副本，再更新全库交接。

绘图默认使用宿主内置 GPT Image 2，以最高质量为目标；未开放的参数如实记录，不把本地参考图读取失败等同于缺少 API 密钥。此准备阶段不会触发单独计费 API。

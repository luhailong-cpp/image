# 五行奇谈 Q 道童八向行走

2026-09-06 重绘。原有 32 个 PNG 路径与每帧 1254×1254 大小保留；全部为真实 RGBA。人物沿用短棕发、纯金发带、玉绿金边短背心、米白短袍裤、太极金葫芦的新道童。

每个方向均由内置 image_gen 独立生成 2×2 行走表，按从左到右、从上到下切为 01–04。共有 south / southwest / west / northwest / north / northeast / east / southeast 八个方向，无代码绘制、镜像转向、静态旋转或复制帧。动画是四帧美术动作；建议每帧 120 ms，实际客户端速度与播放节奏待接入确认。

运行时原点为 (627, 1179)，全部帧的透明边界脚底 y=1179。使用 generate2dsprite 的共同 fit 配置、每方向统一缩放和 feet 对齐；没有逐帧改变缩放。主体平均高度 1085.25–1098.75 px。技能严格检查确认无空帧、无画布触边、无粘贴截断，帧内身体尺度 CV < 0.018，源脚底归一化标准差 < 0.043。西北方向因后斜轮廓窄，单独允许面积度量相对正面差 18%；最终主体高度与正面仅差 0.77%，说明写在 manifest.json 与对应 QC 中。

完整提示词在 prompts/，实际原生尺寸、生成文件标识/哈希、技能参数和视觉验收在 records/。母表实际原生为 1254×1254，每格约 627×627；1254 成品为透明清理、等比重采样与锚点对齐导出，不冒称每帧原生 1254 生成。参考通过只存在内存的 JPEG 参考板传入生图，Windows 本地路径引用失败的事实已记录。

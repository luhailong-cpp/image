- 00 号旧提示词 [walk-W-quarter50-v1/prompt.txt](../../qdao_original_roster_v13/candidate/00_reference_topright_boy/source/walk-W-quarter50-v1/prompt.txt) 第 2 行要求持葫芦手不动，并且每一帧至少一脚着地、禁止双脚腾空。这是步行目标，不符合本次跑步反馈。
- 本次直接查看 00 号 E-contact.png 与 E/01.png：空手在部分帧前后移动，因此不能把“所有帧双手绝对静止”作为结论；持物手和上身接近固定展示姿势。
- 旧导出约束也不适合跑步：V14 [pipeline.py](../tools/pipeline.py) 第 71 行记录 vertical=lowest_alpha_gt_8，[verify.py](../tools/verify.py) 第 68/85 行强制最低非透明像素 y=942；V13 同类规则固定 y=471。沿用此规则会把每帧最低部位拉回固定高度，无法可靠保留跑步腾空相对地面的高度。新跑步导出应保留同一地面/根锚点和真实腾空偏移，不能拿逐帧贴地当无抖动证明。

## 本次修正要点

1. 每个角色保留身份、服装、体态、法器与原有左右手归属；持物手要随肩肘运动，法器随握持点运动，不漂浮或换手。
2. 跑步包含支撑压低、蹬地、短暂腾空、异侧落地，手脚反相；正常游戏显示尺寸也应能看清摆臂。
3. 相位交替必须在完整循环里检查，尤其左右脚、远近遮挡和末帧接首帧；图像数量、SHA 唯一和播放器切帧均不能替代此检查。

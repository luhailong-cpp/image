## v1 检查结果

原 SW01 在统一 1024 画布尺度的 alpha>8 外框为 `[212,152,802,944]`；v1 为 `[190.258,113.506,823.936,948.057]`。可见高度 792→834.551，宽度 590→633.678；相同完整画布展示时人物偏大。强洋红筛查计数 798→0，只能证明该颜色阈值下的变化，不能证明所有边缘干净。

v1 原生透明图在工具的黑底显示中有红黄细碎色边。只读 RGBA 统计与正常 alpha 合成的深浅底 QA 板已经实际查看；512 显示的正常合成结果没有原生工具显示里同样醒目的红黄块。此差别尚不能推出原生边缘完全无污染；判断应以合成显示与细节查看共同为准，不能只看洋红计数。

另有**仅供审查**的完整画布归一化尝试：1254 方图统一下采样到 481 方图，再以整数 `(15,26)` 平移放入 512 方形透明画布，没有局部变形。它基本恢复原来的外框体量，但不能恢复已重绘的脸部/法器细节，因此不据此选用。该参数只是单张诊断，不是逐帧生产规则。

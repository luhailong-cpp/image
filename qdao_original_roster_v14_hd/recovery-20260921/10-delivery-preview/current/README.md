## 注册与导入

统一画布1024×1024，虚拟地面根点为左上原点坐标 `(512,942)`；若导入器使用左下归一化pivot，对应 `(0.5,0.080078125)`。这是人物根点，远近脚的透视深度和步行动作不被强制拉齐到同一屏幕横线。导出仅整画布公共倍率缩小及根点注册，不镜像、不插值、不局部扭曲、不靠重复姿势凑帧。

N为背面，NE为右后，E为右侧，SE为右前，S为正面，SW为左前，W为左侧，NW为左后。各方向01–16独立连续循环。8张idle是独立生成的站姿。

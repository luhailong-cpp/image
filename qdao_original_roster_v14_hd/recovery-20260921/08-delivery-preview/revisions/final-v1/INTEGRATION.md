# 08 炼丹童子：接入数据说明

本包已完成素材制作和离线美术检查；尚未导入或修改 Unity／正式客户端。

- 正式帧：`runtime/walk/{N,NE,E,SE,S,SW,W,NW}/{01..16}.png`，共128张。
- 独立站立：`runtime/idle/{N,NE,E,SE,S,SW,W,NW}.png`，共8张，不复用行走帧。
- 全部为1024×1024透明RGBA PNG。不要把预览GIF、JPG接触表作为运行时资源。
- 行走按01→02→…→16→01循环，每帧30毫秒，一圈480毫秒；独立站立保持对应方向的idle图。
- 统一注册点为左上原点像素坐标 `(512, 942)`。若引擎采用左下原点归一化pivot，对应 `(0.5, 0.080078125)`；接入后仍需在目标场景检查落地与缩放。
- `manifest.json`记录文件、槽位、SHA、来源与锚点。全部八方向分别生成，不依赖镜像切换。
- 避免对透明边缘使用会引入色边的有损压缩。引擎滤镜、图集打包、缩放、排序、运行速度与实际帧时序需在客户端另行验收。

`preview/`只供设计与验收：每方向深浅底循环GIF各1个，以及全帧、脚部原尺寸、首尾接缝和八向站立对照图。`index.html`可直接打开，或通过本机静态服务器访问。

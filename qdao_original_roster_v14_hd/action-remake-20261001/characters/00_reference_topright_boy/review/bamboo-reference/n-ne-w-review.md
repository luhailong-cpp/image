# 竹弓参照：道童 N / NE / W 静态复核

本轮实际看完双方同方向全部 16 帧（共 96 张正式图的六张对照联系表），并放大疑点原图。**未确认新增必须重画槽位；道童当前 48 帧先保留。** 这不是动态验收；本轮没有播放动画。

最新用户认可的竹弓版作为对照，替代月影旧参考。按接触、承重、经过、蹬离、腾空事件比较，不跨方向或跨角色照搬帧号。道童始终保留左手抱葫芦、右手空手。

双方该三方向均为每帧 45 ms、周期 720 ms。道童 N04/N12 比竹弓同号帧更接近离地；NE 两角色半圈领先侧也不同。相同时长不等于相同相位，不能为了同号画面一致而把正确帧降地或换腿。没有仅凭 alpha 最低点认定接地，也没有把侧向视图的前后步距当作叉腿。

本轮源证据见 `n-ne-w-review.json`（逐帧静态相位、保留结论、48 个道童原生 SHA、双方 96 个正式图 SHA）与 `n-ne-w-sources.json`。所有这些 SHA 在观察后复验一致。完整对照是 `compare-{N,NE,W}-{01-08,09-16}.jpg`，仅为整画布等比例缩略诊断图，未修改素材。

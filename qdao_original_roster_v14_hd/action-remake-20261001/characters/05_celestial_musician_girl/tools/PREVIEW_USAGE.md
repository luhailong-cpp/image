# 天音少女正式素材预览

当前入口：[正式动作预览](../preview/index.html)和[跑步节奏检查](../preview/timing-grounding-final.html)。页面内嵌清单，可直接用浏览器打开；通过本地HTTP打开也可。全部图片读取`final/`，不依赖已删除的候选或配准图片。

在本角色根目录重建页面并核验：

```powershell
node tools/build-preview.mjs
python tools/build-timing-preview.py --final
python tools/audit-final.py
```

`tools/build-status.py`在正式清单存在时执行正式核验。上述预览脚本不修改图片；更改正式文件后需重建页面再刷新。

| 动作 | 帧数 | 默认播放时长 |
| --- | --- | --- |
| run | 八方向各16帧 | 75ms/帧，1200ms/圈 |
| hit | E/W各6帧 | 40ms/帧，240ms/段 |
| attack | E/W各12帧 | 30ms/帧，360ms/段 |
| cast | E/W各16帧 | 45ms/帧，720ms/段 |

总计196张1024 RGBA。主预览支持动作/方向、逐帧、正常/慢速、浅深底与透明棋盘。固定根参考线位于(512,942)，不是让每帧鞋底强行贴齐的地面。全角色比例0.65，每段固定源根，底部原点pivot为[0.5,0.080078125]。

跑步只保留正常1200ms/圈（16×75ms）、½×和¼×慢放，提供暂停、逐帧及完整播放一圈。偏快旧档及分相位权重已从当前正式预览移除，历史记录不作当前配置。浏览器时间受刷新率和调度影响，实际世界位移与客户端速度匹配仍待验证。

离线手脚、持琴、透明合成与序列衔接已经复核；预览展示逐图验收记录，不靠文件存在自动判定通过。逐图记录明确区分模型配置目标与未披露的实际型号/质量。

原图和中间图已按用户政策清理，文字来源保留在`provenance/`与正式图片旁。`--candidates`、`--registered`、源图导出和生成工具属于历史制作流程，不能使用已删除的源图片重建交付；当前查看、加载和核验均使用正式文件。

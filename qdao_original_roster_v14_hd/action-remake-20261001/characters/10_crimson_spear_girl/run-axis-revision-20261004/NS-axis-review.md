# N / S 腿脚轴线复核

实际查看当前runtime N/S各16张固定裁切，及原视频8.000–8.917秒连续12fps裁切，8.333秒后可见正面向下的腿部运动；角色较小且有名称/阴影覆盖，不能从视频读出鞋掌微细角度。

N支撑胫—踝—后跟大体同轴，回摆鞋底朝镜头是背向跑步的正常可见面；N02/10轻微侧边露出随整体屈膝/下蹲出现，没有NE15那种由后跟突然变成正面鞋头的翻向。S鞋头持续朝画面下方，支撑腿与鞋面中轴连续；S01/15/16少量鞋底前缘与前掌/抬脚变化一致，未见横向外翻或鞋头突然扭侧。

结论：本轮N/S 32张保持，未发现需要定向重画的明确轴向翻转。这里不是把二维膝踝与鞋尖强行画成直线，也不将视频低清细节当作逐像素证据。四位置各两帧与16×75ms不变。

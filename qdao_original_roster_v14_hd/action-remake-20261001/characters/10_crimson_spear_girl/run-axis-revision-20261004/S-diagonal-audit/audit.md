# 赤枪少女 SE / SW 跑步轴线只读审查

审查对象：已发布 runtime/run/SE、SW 各 01–16，共 32 张。源图仅打开、裁切成审查联系表和计算 SHA256；没有生图、没有改 runtime。源 SHA 见 source-evidence.json。

结论：本轮不能给两方向笼统“脚已全修好”的结论。确认需要优先处理的是 **SW08 抬起靴相对 SW07 的朝向突变**。其余帧未发现同等明确的鞋掌反向或侧向翻折；部分角度只能列为可接受透视或待连续视频校准，不因 16 帧齐全就判动作通过。

## 判断依据和限制

- 看了用户给的山岳守卫 NW 截图：单张显示抬起靴鞋底较正对镜头，可作为用户不接受这类视觉朝向的例子，但截图没有邻帧，不能从它反推出真实三维踝角。
- 看了 reference-motion-review-20261004/character-detail.jpg。角色太小，能读前后摆腿的大势，读不出膝盖朝向、踝内外翻或鞋掌长轴。不能给视频加上不存在的细节证据。
- 斜视图里膝—踝—鞋掌不应在二维上强行共线。正常前后摆腿和后蹬本来会形成二维折角；需要判断鞋头是否稳定指向跑步前方、踝连接是否连续，以及鞋侧/鞋面/鞋底在邻帧中的变化。
- SE 前方为屏幕右下，SW 前方为屏幕左下。支撑脚在身体下方到后方的移动，不等于允许脚在脚踝处向横向突然扭转。
- 本轮只读审查保留既定时序：同脚 8 帧、四位置各两张独立姿势、全周期 16 × 75 ms。没有建议复制、镜像、平移、插帧或调时长来掩盖问题。

## 明确问题

### P1：SW08 抬起的屏右靴突然转向镜头

位置：高处屏幕右边的悬空靴；不是低处屏幕左边的支撑靴。

证据：
- SW05、06、07 这只靴能看到连续的红色鞋面、白色鞋头及窄鞋底边；鞋头/鞋面朝向大致一致。
- 到 SW08，膝和小腿仍保持收起到屏右的关系，但鞋突然显示宽而完整的浅棕色鞋底，鞋头的前向读法明显改变。
- SW07 → SW08 仅 75 ms，鞋底可见面积和鞋面朝向的变化远大于膝部变化；之后 SW09 换脚，未提供延续这一靴底朝向的过渡。
- 这与用户所举“抬靴歪、外翻”的视觉症状相近。明确的是跨帧视觉朝向不连续；仅靠这张绘画不能下医学意义的踝外翻诊断。

建议修改范围：
- 优先只重画 SW08 高处悬空腿的膝—踝—鞋连续关系，沿 SW07 的摆腿平面继续屈膝。
- 独立姿势差异可来自屈膝量、脚踝的自然伸屈和脚尖高度，不靠“整片鞋底转向镜头”表示动作。
- 低处支撑靴的第四位置、人物上身和两只手握枪不应跟着改变。
- 修后实际对比 SW06–09，不能只检查单张鞋看起来顺眼。

联系表：SW-01-08-legs.jpg；可直接看 runtime/run/SW/07.png、08.png。

## 待根代理合并连续视频后的校准项

1. 视频连续抽帧若能读出膝部轨迹，校准 SE / SW 前后摆腿的运动平面。当前低分辨率 character-detail 不能确认细鞋轴。
2. 动作幅度与参考视频相似与否应另审，不能把“没有明显外扭”升级成“符合视频”。
3. 正常速度重点观察 SW07 → SW08 → SW09，再看 SE07 → SE08 → SE09；前者已有明确单帧朝向突变证据，后者尚未见同等级问题。
4. 现有旧 contact-audit 中“neither ankle rolls outward”等总括判断不够严格。本次记录明确保留 SW08 问题，不沿用旧批准结论。

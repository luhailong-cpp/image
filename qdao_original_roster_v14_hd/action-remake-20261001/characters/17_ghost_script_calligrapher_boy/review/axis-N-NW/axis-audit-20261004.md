# N / NW 正式运行帧腿脚长轴复核

本次仅检查 `runtime/run/N`、`runtime/run/NW` 的 32 张正式 1024 PNG，不更换选图，不修改图片，不作全套动作验收。逐图输入 SHA-256 见 `input-runtime-sha256.json`。已看全身 240px 联系图、放大腿部图，并对 18 张疑点及邻帧另看原尺寸。

最小优先修复集合：**N16、NW15**。这是可见的连续性/踝足转向问题，不是从视频估计出的精确三维角度。其余帧未发现足以单独触发重画的明确轴向硬错；这不等于逐帧接地、身体动态和完整动作均已通过。

## 判定与边界

- 后视的摆腿折膝会自然露底；不能把露底面积、鞋底不好看或单纯画面倾斜当作外翻。
- 观察小腿接入踝口、跟帽中心、鞋前掌长轴与相邻帧可见侧面的关系。裤管遮住膝点时，只描述可见链条，不伪造精确关节坐标或度数。
- 视频 `reference-motion-review-20261004/character-detail.jpg` 只用于直向运动、膝脚随前进方向推进的总体参照。像素模糊，不用于鞋尖/踝骨细节断言。
- 剪贴板截图中的角色并非 17，不作为 17 当前帧证据。
- 保持 16 × 75ms = 1200ms；同一脚半周期支撑、每位置两张独立姿态的既定结构不改。局修只能改真实膝踝鞋形，不能整图旋转、升降或复制帧。

## 最小局修说明

**N16：解剖左支撑脚，优先级高。** N14 后跟近正后视；N15 可见少量斜露底，仍可解释为正常抬跟。到 N16，小腿进入踝口后，跟帽中心偏到鞋的右上侧，鞋底长轴却斜向画面左下，外侧面在单帧明显换边，形成踝口以下的侧向折转。问题不在露底本身，而在 15→16 的踝—跟—前掌关系不连续。保持左腿是支撑腿、右脚将落的阶段，参考 N14/15 的踝中线收正 N16 左靴的横向滚转；仍允许向后蹬离时自然抬跟。不要把 N15 自动连带重画。

**NW15：解剖左摆脚，优先级高。** NW14、NW16 的近侧摆脚鞋底呈连续的斜向纵长形；NW15 同脚突然成更横向的宽侧影，前掌横伸，而膝到踝仍沿原来屈腿链条。14→15→16 中孤立横转在 240px 也可见，读成侧甩脚。保留当前左膝高度与右支撑腿，只调整左踝接入与鞋掌的偏转，使其在原三分之四后视平面完成摆腿。允许踝屈伸改变露底，不应只是遮掉鞋底。先修 15，再复看 14–16，不自动重画 14/16。

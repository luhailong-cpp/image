# 提灯童子 V12

制作中，未发布。角色使用新道家服装肖像和八向中性站姿：雀斑圆脸、棕色双麻花辫、赭黄短披肩、砖红交领短道袍、米白裤、棕布靴，实物纸灯始终由人物左手提着。前腰玉佩、葫芦不能跑到背面。不增加梦幻光效、幻想盔甲或其它角色的器物。

最终规格：8方向×8张真实走路帧、8张独立站姿、8条横排精灵图、8个循环GIF和1张1024肖像，共89个正式媒体。走路/站姿导出512×512 RGBA，GIF每帧60毫秒。512是导出尺寸，原生生成尺寸及裁格来源另存，不能称全部原生512绘制。

南向8步保留已修正原画；北向02/03/04分别单独重绘对侧后跟、经过和前抬膝。其它方向用角色对应neutral作为身份参考、韩湘子已经验收的同向8步作为纯姿势参考重新绘制女孩。参考表按原05–08、01–04重排，匹配本角色右腿先迈的相位约定；参考图片不直接进入最终素材，人物、服饰、灯和步态图均由内置image_gen画出。references中的PNG与JSON记录原始SHA和格号。

source保存原图与拒绝采用/局部修正候选，prompts保存对应生成提示词。corrections.json与assemble_corrections.py只把独立生成的修正格按原格尺寸等比插回，不绘画、不镜像、不复制或插值凑帧。rebuild.py完成方向配对、透明处理、共用一次缩放和身体轴对齐，再进行数值验证；每次重建都需要重新查看变化后的图。

使用公共对齐v2：上部42%且alpha>8像素的水平中位数置于x256，脚底最低alpha>8像素置于y471；全72帧共用统一缩放，只作整帧平移。公共边缘去洋红参数只处理已确认的边界污染，保留透明度和几何。肖像为用户已确认的新道家身份替换，不沿用旧服装V11肖像。

最终证据将包含qc.json、validation.json、processing/visual-review.json、逐方向视觉排版和SHA封存记录。数字通过不代替实际逐帧的腿部、方向、持灯手和边缘复核。

# 八位人物的道家风格评审

更新：2026-09-13，按用户最新纠正“就是道家Q版本”“不要梦幻风格”修订。目标为**明确道家主题的 Q 版人物**。Q 版只决定头身比例、脸型和画法；人物的道家依据应体现在服饰、发髻、器物和已确定的角色身份中。

对象为 v11 正式八人总览和现有设定；原 `24_crane_hermit` 不在名单内。当前 23、25、26、27、28 已生成独立的新服装基准及八方向站立候选；完整八帧行走尚在制作，未发布到游戏。原 V11 正式素材保留。

## 当前判断

不能认定八人都已充分体现道家主题。吕洞宾、何仙姑、韩湘子已有八仙角色身份与对应器物，其中吕洞宾的整体服装识别最直接；其余五人的主要视觉身份仍是送灯人、护卫、药师、游侠和机关师，道家关联需要加强。灯笼、桂花、月兔、古装、云纹和玉绿配色本身不足以证明道家身份。

保留已确认的八张脸、直发、胖瘦、年龄感和职业，不借本次纠正将全员改成同一种道童。以下小改路线已用于五位角色的候选服装基准；凡确定采用的外观调整，都须同步到立绘、八方向行走和独立站立。

## v12 制作和验收

- 风格表述与提示词统一使用“明确道家主题、高清手绘、Q 版比例”；不再把泛国风、节庆装扮直接判定为道家风格合格。
- 不改八人的名字、脸型、年龄、体态、直发特征和主要职业器物；小范围服饰调整也应有一张一致的角色基准，随后才生成完整动作，避免站立与行走变成不同造型。
- 每方向八个真实步态，另做中性独立站立。人物身份与衣物一致、左右脚交替、配件固定、八方向可辨、身体完整、脚点和循环衔接分别验收。
- 黄、红、靛青、墨玉、紫杏、粉绿、天青等个人配色继续保留。不同年龄、男女和职业不要求使用同一套发髻与服装。
- 太极佩、葫芦、符袋等只作克制且能看清的具体物件；不堆砌巨大符阵、浮空零件或强烈发光特效。云纹和节庆挂饰仍可保留，但不充当道家身份的唯一依据。
- 文中的服饰路线是游戏美术调整建议，并未宣称复原特定道教服制或确认任何未设定的门派身份。

# 韩湘子 V12

状态：素材制作、全部视觉复核和数值验收已完成；游戏发布与Unity运行验收由主任务继续。

角色保持用户指定的传统道家 Q 版：黑色短发与发髻、蓝布带、蓝白交领短道袍、深蓝裤、裹腿布鞋、腰侧竹笛和花形玉饰。无梦幻光效、法术装饰或幻想盔甲。沿用已验收 V11 肖像，文件哈希保持一致。

正式交付为 64 张走路帧、8 张独立站立图、8 条横排精灵图、8 个循环 GIF 和 1 张肖像，共 89 个正式媒体文件。走路和站立均为 512×512 RGBA，横条为 4096×512，肖像为 1024×1024；GIF 每方向 8 帧，每帧 60 毫秒。

对齐版本2的根点是(256,471)：X取主体上部42%且alpha>8像素的水平中位数，Y取脚底最低alpha>8像素。脚掌可在身体轴左右移动，避免换支撑脚时整个人横跳；72张图仍只做整帧平移和同一个统一缩放。

所有原画由内置 image_gen 生成。source 保存原始及修正 PNG，prompts 保存对应提示词。八个 phaseXX-turnaround.png 按 N、NE、E、SE、S、SW、W、NW 排列，assemble_phases.py 将相位表转置为方向表。单独生成的错误帧修正由 assemble_corrections.py 裁格重插，各层 assembly.json 记录原图路径、哈希、原始尺寸和裁切来源。

原始八视角图通常为 1774×887（每格443×443，余下边缘为洋红空白）；单帧修正通常为1254×1254，2×2修正图也是1254×1254。组装只按原始格尺寸做等比归一，不能把派生1772×1772组图称作原生高分辨率绘制。无镜像、重复帧、像素插值造动作或按人物大小逐帧拉伸。

rebuild.py 执行原画重组、统一透明清理、全72帧共用一次等比缩放、位置对齐和导出，再运行独立文件检查。component-padding=0用于完整保留连通人物的实际边界：原图个别鞋底后仅有1像素空白，额外裁切外扩会碰到格边；实际人物未裁断。不放宽空帧、贴边、大小稳定性或锚点检查。

clean_export_edges.py 将残留洋红底色替换为邻近已有主体颜色，只改RGB，所有透明度、轮廓、像素位置和人物结构保持不变。肖像不参与此清理。

make_review.py 只制作验收排版，不绘制人物。processing/visual-walk-*.jpg 展示全部64帧，visual-idle.jpg 展示8个独立站姿，visual-edges.jpg 展示浅深背景透明边缘，animation-overview.gif 汇总八方向播放。qc.json、validation.json、processing/visual-evidence.json 共同记录最终验收；每次重新导出后必须重看受影响的图像，不能沿用旧的视觉通过状态。


最终逐帧视觉记录：processing/visual-review.json。六格摆臂修正原图为1536×1024的3列2行图，原格512×512，仍按格尺寸等比归一后进入统一导出。最后一次只改西北01摆臂及其横条/GIF，其余86个媒体文件的哈希保持不变，见processing/last-correction-validation.json。

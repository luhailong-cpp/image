# 吕洞宾：有限范围的洋红残边清理原型

本目录是三张已导出 idle 的副本实验，未修改正式 64 walk、8 idle、肖像、原画、共用处理器、V11 或客户端。运行脚本为角色目录的 `despill_prototype.py`，全部处理使用 Pillow/Numpy，无额外图像生成或姿势绘制。

`comparison-head.png` 与 `comparison-full.png`：每行 N、S、NW；四列依次为深底处理前、深底处理后、浅底处理前、浅底处理后，采用真实 alpha 合成。

限制为距离 alpha<=8 像素不超过欧氏 2px 的轮廓带，仅选择 R-G>=12、B-G>=12、B/R>=0.8 的明显洋红像素。明显红色 R-G>=30 且 R/B>1.3 强制保护。附近 6px 内搜索 alpha>=224 的无洋红参考像素，保留原 G，将受污染 R/B 仅向下压至该局部参考的相对色度；无可靠参考就不改。不会扩展修改范围到 6px，6px 只用于取色。

逐像素断言：alpha 全字节相同、G 全字节相同、轮廓外及内部像素相同、保护红色相同；没有缩放、平移、重采样、复制或生成动作。最大实际处理半径为2px。输入与输出哈希、改动像素及范围见 `report.json`。

三张分别改动 N 2350、S 2411、NW 2308 像素，约占可见像素4.4–4.6%。主要头发及衣物紫边明显减弱，发簪、面部、红穗和几何保持。原型刻意保守：2px带内还有55/56/128个找不到可靠取色的候选未改；带外还有568/517/627个紫色候选未动，部分细发丝和颈侧仍可看到残色。本报告不声称已彻底去除所有残边。

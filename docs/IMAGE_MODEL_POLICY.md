# 最新 GPT Image 选择策略

## 每个新生图任务必须执行

1. 查阅 [OpenAI 官方模型目录](https://developers.openai.com/api/docs/models)和对应图像模型页面，核对最新正式 GPT Image、最高能力版本、最高质量参数及当前入口是否支持。同一任务或批次沿用已核对结果；用户明确指定的模型或质量优先。
2. 使用真实可用模型 ID。2026-09-16 的已验证基线是 GPT Image 2.5 Sunburst（`gpt-image-2.5-sunburst`），最高质量为 `max`。未来型号及质量枚举须重新核验，不臆造 `gpt-image-latest` 等别名，不将速度优先版本自动当作最高能力版本。
3. 有模型／质量选择器时，必须显式设置本次确认的型号和质量；使用 CLI 时显式参数覆盖旧的本地默认值。工具内的固定默认只是最近验证基线，不是自动更新服务。
4. 优先检查宿主内置 `image_gen`。没有选择器时，提示词只能表达目标，无法强制切换后端。官方或运行时明确仍旧时，不以该路径继续生成并冒充最新版；后端未知时说明“宿主管理，最新版未获验证”。要求严格锁定型号时，仅使用已获授权、能显式指定模型的路径。
5. 内置与 API 是不同入口。API 的单独计费授权和凭证要求保持不变；最新版策略不自动授权付费 API，也不把参考图读取故障解释为必须配置密钥。
6. 最新型号／可用性无法核实时，报告缺少的证据。保留最近验证基线作为排障参考，不将它称为已确认的最新版，不静默降级。记录本次核对日期、目标、实际传入参数和后端返回信息。

## 当前能力核对

2026-09-16 查阅的[宿主生图说明](https://learn.chatgpt.com/docs/image-generation)仍注明内置路径使用 `gpt-image-2`；本会话 `image_gen` 工具只开放提示词及参考图输入，没有模型或质量参数。因此本次修改落实的是每任务核对与选择规则，不能改变该服务的隐藏后端。

[Sunburst 官方页面](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)确认它可在 Image API 或 Responses API 图像工具中显式选择。若未来宿主开放模型选择或公布后端升级，以新的官方资料和本次工具能力为准。

此策略由 Codex 在处理新生图任务时执行。直接运行固定 CLI 默认值、修改提示词、修改 Codex 的文本推理模型，都不等于获得一个自动跟随最新版的图像后端。

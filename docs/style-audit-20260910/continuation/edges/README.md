# 走路帧与正式宠物：当前版本补充实看

本次逐张查看了 **32 个方向动画帧和 4 只正式宠物透明 PNG**。所有原画风格均属于指定参考体系，可保留；剩余问题是局部透明边缘质量，不需要把角色或宠物整体换风格。

- **32 帧道童**：每帧都独立查看了发梢局部，在浅色底和深玉绿底均能看到品红细边及零星突出像素。这次结论来自 32 张分别放大确认，不是把单帧结果推广到全部。绿金米白配色、Q 版比例、金发带、葫芦和短红穗保持统一。
- **狐团团、符小虎、云啾啾**：整张风格一致。腹部、脚边或羽尖内隙存在零星极细粉紫残色，缩略整体并不突出，列低优先级局部修边。正常的红流苏、红冠、金饰与毛色不算污染。
- **灵月九尾狐**：狐吻、尖耳、九尾和淡紫冷白毛与参考一致。两处尾毛内隙看到偏粉细线与阶梯状细毛，列低优先级边缘修整。淡紫毛色本身保留，不能按颜色阈值整片去紫。

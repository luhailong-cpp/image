# 项目绘图偏好

- 在本项目生成或编辑图片，默认使用 GPT Image 2（`gpt-image-2`），以最高质量为目标；用户明确另选模型或质量时遵从该次要求。
- 默认直接使用 ChatGPT/Codex 宿主内置 `image_gen`；官方说明该路径使用 `gpt-image-2`，计入 Codex 用量，不需要单独配置 `OPENAI_API_KEY`。以最高质量为目标；工具若开放模型和质量参数，显式设置 `model=gpt-image-2`、`quality=high`；尺寸按素材用途和用户要求选择。
- 内置工具未开放模型或质量参数时，按其实际能力调用，区分官方说明与本次请求能验证的参数，不宣称已强制设置 `high`。参考图的本地读取失败时，优先排查输入通道并在工具支持范围内使用对话图片参考；这类文件故障不代表内置生图需要 API 密钥，也不能把缺少密钥当作内置生图的前置阻塞。无法继续时说明实际错误，不静默换成较低模型。
- API/CLI 是用户明确选择时的备用路径，不是默认出图方式。使用时沿用当前环境已有的 `gpt-image` 工具，显式传入 `--model gpt-image-2 --quality high`。单独计费路径须有用户授权；凭证只从当前电脑的安全配置读取。已有备用路径授权不改变用户最新要求的内置生图优先级。
- 换电脑时将本文件随项目一起同步，在新环境确认内置生图工具或相应 CLI、账号权限可用；本文件保存项目偏好，不负责同步账号、凭证和用户目录工具。安装细节见 [工具移机说明](docs/AI_DESIGN_TOOLS_SETUP.md)。
- 制作游戏素材前，阅读 [README 的接手说明](README.md#给接手的-codex) 指向的交接与美术定调文档。
- 制作、修改、实现 UI 或重新切图，以及收到其他游戏截图时，先读 [UI 制作规范第 2 节](qdao_ui_redesign_v5/UI_SPEC.md#2-统一视觉与控件层级)：按指定风格图和提示词执行，保留道家 Q 版与春节／元宵／中秋点缀；其他游戏截图默认只参考功能，不改变美术风格。

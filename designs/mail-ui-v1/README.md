## 设计

整体使用深玉绿、象牙米白、暖金手绘框体，以及太极、葫芦和少量短穗。活动横幅保持金发带 Q 道童、玉兔、桂枝、月轮、青绿仙山与玉瓦道观，节庆只作适量点缀。用户的其他游戏截图用于参考功能，未沿用对方的美术皮肤。

左侧是分类与邮件列表，右侧是详情；有活动图时位于标题与正文之间，无图时正文上移。附件与操作独立呈现，避免横幅挤掉领取入口。原生文字与无字横幅分离，后续运营图片更新无需重做整个界面。

整屏手绘稿展示美术目标；交互预览使用当前项目独立控件组合，验证可读性与状态，二者不逐像素相同。目标横屏布局为 2560×1080，同时提供窄屏排布。

## 演示范围

演示支持分类和邮件切换、读取、单封与一键领取、清理已读、附件保护、过期禁领、活动详情、关闭/重开及本地状态保存。阅读与领取分开，清理已读保留有效待领附件。

邮件、奖励、数量、日期和活动规则均为界面示例。本轮为美术与本地交互预览，未接入 Unity 邮件窗口或在线邮件服务。

## 生成方式

三张新图使用宿主内置 image_gen；没有调用外部收费 API。工具未提供 model 或 quality 参数，未宣称显式设定 high。当地文件参考读取触发 Windows sandbox ACL 初始化错误后，使用已显示的项目风格参考图，通过对话图片输入成功完成生成。实际原生尺寸、来源与 SHA-256 见生成记录。

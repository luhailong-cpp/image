## 美术基线

- 以 [已确认 designs 风格](../README.md)和[结伴同游样板](../team-ui-v2/team-ui-v2.png)为主要参考，保持圆润饱满、明亮干净、细腻手绘体积与温润材质。
- 延续每位 NPC 的职业、年龄、脸型、发型、短身短肢比例、主色和标志道具；原有道家气质通过云纹、太极、葫芦、玉佩等合适元素保留，不给所有职业统一加同一种道具。
- 春节、中秋元素融入衣缘、腰饰、发带和随身物件：按人物职业选择朱红结绳、暖金团花、灯笼穗、月纹玉佩、桂花或玉兔香囊。装饰清晰可见且疏密有序，人物主色和身份仍易辨认。
- 原游戏截图用于身份与道具参考；成图的画法以 designs 为准。保留儿童、青年、壮年、老者之间的差别。
- 全身单角色、真正透明背景、完整轮廓与安全边距；本轮用于主城静态 NPC，未制作动画或接入客户端。
- 第 21–23 位沿用原批次“截图局部可见、按职业原创补全”的明确标记。

## 后续入口

- 内置入口：无需 API Key，继续按已授权绘图范围工作；保存并如实报告实际返回像素，不承诺未开放的尺寸参数。
- API 备用入口：仅在用户明确选择后使用；单独计费，需要本机 API Key。拟按角色宽高比例选择 2160×3840、2560×3200 或 2880×2880；这些约 820 万像素尺寸高于官方 experimental 门槛，必须以实际返回尺寸和视觉验收为准。先验收单张，再扩展整批。

官方参数说明：[图像提示指南](https://developers.openai.com/api/docs/guides/image-prompting)、[图像生成指南](https://developers.openai.com/api/docs/guides/image-generation)。最高质量参数与尺寸分别核对。保留全部尝试记录，生成成功后才标记为交付。

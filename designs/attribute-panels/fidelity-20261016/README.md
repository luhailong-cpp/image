# 人物与宝宝属性：v10 HTML 原生还原包

依据最新 `v10-preview/index.html`、`panel.css`、`app.js`。已实看本轮旧原生人物和宝宝截图，确认旧版方案在左、右侧大步进器，与 HTML 的分栏、字体和按钮槽位不同。31 张客户端属性 Sprite 与正式切片源逐张 SHA 全部一致，因而没有重生图或新增 PNG。

本包将 v10 的 1600×675 stage 按 1.6 转为游戏 2560×1080 坐标：面板 2278.4×912，左上 140.8/89.6。人物采用属性总览/加点两区，方案移到右上，三操作按钮同一底行。宝宝采用名单/六属性/加点三栏，头像保持小图，详情头像由真实所选宝宝解析；四项纵向滑杆复用原 `UiPointRow` 的权威上下限和待提交模型，多余维度可滚动。保留原来的方案、装备、战斗属性、图鉴、改名、出战/收回及洗点入口。

代码以三个 `partial` 局部布局文件接入，原主脚本仅加入布局钩子、局部几何引用；`CharacterAttributeVisuals`、`PetUiStyle`、全局字体和配色文件均未更改。错误状态颜色保持原 setter 的结果。无相性点筛选、真实权限、Busy 锁定、服务器同步、预分配、重置和确认事务全部保留。

`installation-manifest.json` 的八个文件与技能包的三个文件需一起安装。运行时旧脚本保留原 meta；新文件使用包内 meta。安装前检查各 `.source.json` 的源 SHA。`verify-panels.cjs` 去除明确的表现层钩子/几何差异后，三个原主脚本与 checkout 业务源码逐字一致。`qa/compile-report.json` 记录 459 源文件 overlay 编译通过、零错误、无缺失引用。

本包未写客户端、未启动 Unity。旧截图只用于发现差异，不能代表此包验收。安装后请重新执行原属性截图入口，检查普通人物、八维滚动、四宝宝、空名单、十宝宝末页及两种分辨率；尤其检查 Tooltip、滑杆键盘焦点、图鉴覆盖与新增纵向滚动。

技能包依赖本包的 `AttributeFidelityLayout.cs`，只能供这三个面板调用。重建暂存与检查依次运行 `stage-panels.cjs`、`compile-panels.ps1`、`verify-panels.cjs`。

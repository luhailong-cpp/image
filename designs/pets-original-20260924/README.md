# 五行奇谈 · 原创宠物素材包

2026-09-24 用户明确要求更换身份与关键造型元素，神兽、变异、元灵同样按原创方案重新设计。本目录为新的正式工作目录；旧 `pets-20260924` 是未采用候选，仅保留来源证据。

当前正在准备 14 项原创方案，尚无可交付宠物图。这里没有复制旧宠物图或外游截图。生成时只附 `designs/` 已确认画法作为风格参考，另一个朝向可附本包同宠原创源图来保持一致。

技术规格保持：原生短边至少 1024；每宠 E/W 分别绘制，导出 1024×1024 真透明 RGBA，共同缩小因子，脚点 `(0.5,0.08)`；UI 含 1024 全身与人工取景的 512 头像，不上采样，不把全身缩图当头像。原生文件、逐图模型证据、提示词和派生哈希链保留。

这是一套静态双朝向素材，不包含动画或客户端接入。`E` 敌方左上朝向右下，`W` 我方右下朝向左上。技术验证不等于原创差异审查、用户确认或引擎验收。

## 工作文件

- `asset-config.json`：待填新的 14 项方案、朝向脚点和头像裁切框。
- `build_pack.py`：透明提取、保守噪点清理、双向统一比例、来源与派生记录。
- `build_overviews.py`：仅排版现有 PNG 的正向与双向总览。
- `validate_pack.py`：尺寸、透明、触边、来源哈希及参考图政策检查。
- `source/`、`prompts/`、`records/`：新原创图和实际生成证据；旧图不迁入。

```powershell
python designs/pets-original-20260924/build_pack.py
python designs/pets-original-20260924/build_overviews.py
python designs/pets-original-20260924/validate_pack.py --require-complete
```

身份、轮廓、服装、主要装饰与道具需逐只审查，不能仅改名、改色就认为已形成原创差异。此项为美术审查范围，不代表法律结论。
